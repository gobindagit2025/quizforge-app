# 🎯 QuizForge — Test Your Knowledge

A modern, interactive quiz web application built using HTML, CSS, and JavaScript.  
It fetches real-time questions from the Open Trivia Database API.

---

## 🚀 Features

- 🎮 Multiple difficulty levels (Easy, Medium, Hard)
- 📚 Category selection
- ⏱ Timer-based questions
- 📊 Live scoring system
- 📈 Progress tracking
- 🎉 Result screen with stats
- 🔁 Restart & replay functionality

## ⚙️ How It Works

1. User selects difficulty & category
2. App fetches 10 questions from API
3. Each question has:
   - 4 options
   - Timer countdown
4. Score is calculated based on:
   - Correct answers
   - Remaining time
5. Final result shows:
   - Score
   - Accuracy
   - Performance feedback
